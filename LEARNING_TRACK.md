# AI QA, AI Security & AI DevOps — Hands-on Learning Track

This **public** repository is a safe, synthetic-data demonstration and teaching workspace. It is NOT production client work, not a live LLM integration by default, and not evidence of hands-on employment experience in agentic AI.

## Learning streams
- Python, pytest, typing/async, APIs, FastAPI/Pydantic, Playwright and CI/CD architecture.
- LLM and RAG evaluation: datasets, grounding, correctness, regressions, robustness, latency and costs.
- Agentic AI/MCP: tool permissions, integration contracts, structured traces, failures, human approval.
- AI security: prompt injection, data exfiltration, safe tool calling, adversarial/negative tests, audit.
- AI DevOps: safe release gates, model changes, tests, observability, failures/rollbacks, cost budgets and runbook.
- Integration with realistic business scenarios across software and nontechnical customer workflows.

## Daily lesson structure
1. One practical scenario and architecture.
2. Executable synthetic code with explicit files/commands.
3. Positive and **at least two negative tests**.
4. Expected output distinguished from actually run output.
5. Reproducible troubleshooting and success criteria.
6. Portfolio showcase artifact and a few senior interview questions.
7. Next 30–90 minute exercise.

Carry forward previous verified exercises rather than claiming completion automatically. On Sundays compare completed lessons and artifacts with the skills gaps and set next week's one capstone increment. Never include credentials, real customer data or private proprietary AI Evolution source code.
