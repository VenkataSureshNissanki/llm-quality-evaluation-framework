# AI Assurance Learning Track — V1
Purpose: one separate continuous learning task for AI QA / model and agent evaluation, AI DevOps/CI-CD/observability and AI Security/guardrails.
Daily: one compact lesson with concrete concept, realistic synthetic use case, runnable Python/pytest or workflow, negative tests, expected results, interview exercise, and portfolio documentation to practice after office.
Weekly: revisit lessons, verify tests and observed outputs, list skill gaps, adjust next seven-day curriculum based on credible job and AI Evolution needs.
Practice stages: evaluation fundamentals -> LLM/RAG metrics -> agents/tools/MCP -> injection and tool authorization defenses -> CI release gates/monitoring -> full reproducible AI assurance demo.
This is a public portfolio repository. Use only non-sensitive synthetic data. Never claim labs are prior paid client experience, or claim code was run unless outputs were inspected.
No deployment or code merge without human approval. Separate from the Master Portfolio Coordinator's job/business research and from non-QA income exploration.
