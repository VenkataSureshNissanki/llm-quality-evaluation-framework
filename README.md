# AI Quality & LLM Evaluation Framework

Offline Python portfolio demo using **synthetic, predefined responses**. Checks required phrases, prohibited text, context cues, expected refusals, email exposure, and length. This is *not* a live LLM integration or a claim of hallucination-free output.

```bash
python scripts/run_demo.py
python -m unittest discover -s tests -v
```

Sample JSON reports are generated in `demo_output/`. No API keys or dependencies required. Intended as an independently created skills demonstration, not client work.
